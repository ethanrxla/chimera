# Chimera Data Models

This document defines the data structures for the various YAML and JSON files used throughout the Chimera pipeline, with a particular focus on the canonical `Finding` schema.

---

### `scope.yml`

*   **Stage:** Requirement Analysis
*   **Purpose:** Defines the scope and rules of engagement for a test.

```yaml
# A list of targets that are explicitly in scope. Can include domains, subdomains, and CIDR ranges.
allowlist:
  - "https://example.com/api/v1"
  - "https://*.example.com"
  - "192.168.1.0/24"

# A list of glob patterns or specific targets to explicitly exclude from the scope.
denylist:
  - "https://admin.example.com"
  - "*.thirdparty.com"

# Notes on authentication requirements and methods for the target application.
auth_notes: |
  - Use API key 'xyz-123' in the 'X-API-Key' header.
  - OAuth 2.0 with client credentials flow.

# Proof of authorization for performing the security test.
proof_of_authorization: |
  - "See attached authorization letter from security@example.com"

# Rate limiting policy for the entire run.
rate_limits:
  requests_per_second: 10
  concurrency: 5

# Allowed HTTP methods for tools that perform web requests.
allowed_methods:
  - "GET"
  - "POST"
  - "PUT"
```

### `Job` Object (Internal Representation)

*   **Module:** `chimera_core.job`
*   **Purpose:** Tracks the entire lifecycle and state of a single Chimera job run.

```python
# Simplified representation (full dataclass in chimera_core/job.py)
@dataclass
class Job:
    job_id: str
    scope_manifest: Dict[str, Any]
    scope_hash: str
    mode: str
    created_at: datetime
    created_by: str = "system"
    status: JobStatus = JobStatus.CREATED
    started_at: Optional[datetime] = None
    ended_at: Optional[datetime] = None
    targets: List[Dict[str, Any]] = field(default_factory=list)
    events: List[Dict[str, Any]] = field(default_factory=list)
    findings: List[Dict[str, Any]] = field(default_factory=list)
    artifacts: List[Dict[str, Any]] = field(default_factory=list)
```

### `ExecutionPlan` (Internal Representation)

*   **Module:** `chimera_core.planner`
*   **Purpose:** A Directed Acyclic Graph (DAG) of `Task` objects, representing the test plan generated by the planner.

```python
# Simplified representation (full class in chimera_core/planner.py)
class Task:
    task_id: str
    tool: str
    target: str
    options: Dict[str, Any]
    dependencies: Set[str]

class ExecutionPlan:
    tasks: Dict[str, Task]
    graph: Dict[str, List[str]] # Adjacency list
```

### `Finding` Schema (Normalized Output)

*   **Module:** `chimera_core.models`
*   **Purpose:** The canonical, unified schema for all security findings generated by Chimera, regardless of the source tool. This enables consistent storage, deduplication, and reporting.

```python
# (Full dataclass in chimera_core/models.py)
@dataclass
class Finding:
    finding_id: str           # Unique stable hash (e.g., SHA256 of core identifying fields)
    severity: str             # e.g., "info", "low", "medium", "high", "critical"
    title: str                # Concise title of the finding
    description: str          # Detailed description of the vulnerability
    affected_target: str      # The specific host/path/method/IP affected (canonical form)
    tool_source: str          # The ID of the tool that generated this finding (e.g., "net-utils")
    tool_version: str         # Version of the tool that generated the finding
    run_id: str               # The ID of the job run that discovered this finding
    scope_hash: str           # The hash of the scope manifest for this run
    evidence_refs: List[str] = field(default_factory=list) # References to artifacts (e.g., file paths, URLs)
    repro_guidance: Optional[str] = None # Steps to reproduce, non-exploitative
    timestamps: datetime = field(default_factory=lambda: datetime.now(UTC))
    status: str = "new"       # Current triage status (e.g., "new", "triaged", "duplicate", "invalid")
```

### `execution.yaml` (Future Tool Configuration)

*   **Stage:** Tool Selection & Configuration (currently integrated into `ExecutionPlan` tasks)
*   **Purpose:** Defines how a specific tool should be executed for a given task. (This concept is now largely absorbed by the `Task` object within the `ExecutionPlan`.)

```yaml
# Example of how a task might represent tool execution parameters
# Note: This is now part of the Task object in ExecutionPlan
tool: "Autoswagger"
version_pin: "v1.2.3"
targets:
  - "https://example.com/api/v1"
rate_limits:
  requests_per_second: 5
artifacts_path: "/chimera/artifacts/autoswagger-run-456"
```
